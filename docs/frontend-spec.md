# Фронтенд панели управления кампаниями Keitaro (MVP)

## 1. Цель
Разработка веб-интерфейса на **Vue 3 (Composition API)**, **Tailwind CSS** и **PrimeVue 4** для управления кампаниями Keitaro.

## 2. Стек
- **Framework**: Vue 3 (Vite)
- **Styling**: Tailwind CSS
- **Components**: PrimeVue 4 (DataTable, Dialog, Toast, InputText, Button, Dropdown, etc.)
- **State**: Pinia (для хранения данных кампаний и операций)
- **HTTP**: Axios / Fetch (интеграция с бэкендом FastAPI)
- **Icons**: PrimeIcons / Lucide Vue

## 3. Экраны (согласно ТЗ бэкенда)

### 3.1. Экран «Кампании»
- **Поиск**: По ID (точное совпадение) или названию (частичное, без учёта регистра).
- **Список**: Таблица (PrimeVue DataTable) с колонками:
  - ID кампании
  - Название
  - Группа
  - Источник трафика
  - Состояние (`active`, `disabled`, `archived`)
- **Пагинация**: `limit` (1–100), `offset`.
- **Создание**: Модальное окно (PrimeVue Dialog) с полями:
  - Название (обязательно)
  - Исключённые страны (список ISO alpha-2, валидация)
  - Оффер (поиск по ID/названию)
  - Домен, Группа, Источник трафика (выбор из справочников или дефолты)
  - Кнопка «Создать» (с поддержкой `Idempotency-Key`)

### 3.2. Экран «Карточка кампании»
- **Заголовок**: ID, Название, Состояние, Ссылка (`campaign_url`).
- **Настройки**: Домен, Группа, Источник трафика.
- **Страны фильтрации**: выбор исключённых стран (`GET /api/v1/references` → `countries`, валидация ISO alpha-2)
  и сохранение через `PUT /api/v1/campaigns/{id}/country-filter`.
  - Список стран попадает в фильтр `accept` потока `forced` с редиректом на Google.
  - Если потока с редиректом нет — он создаётся; при пустом списке поток отключается.
- **Потоки**: Список потоков (PrimeVue Accordion или Tabs):
  - Позиция, Тип (`forced`, `default`), Состояние, Условие, Редирект (для `forced`).
  - **Схема с офферами** (для `default`):
    - Таблица привязок офферов: `offer_id`, `name`, `share`, `state`.
    - Режим распределения: `equal` / `explicit`.
    - Кнопка «Сохранить» (отправка `PUT /streams/{id}/offers`).
    - Индикация возможности редактирования (`can_edit_offers`, `edit_disabled_reason`).
- **Создание потока**: если в кампании нет потоков с офферами, карточка сообщает об этом и предлагает
  кнопку «Добавить поток с офферами»: название, тип (`regular`/`default`), выбор офферов чекбоксами.
  `POST /api/v1/campaigns/{id}/streams`, доли делятся поровну.
- **Операции**: История изменений (UUID, статус, этап, код ошибки).

## 4. API-интеграция (Бэкенд: FastAPI)
- `GET /api/v1/campaigns`
- `GET /api/v1/references`
- `GET /api/v1/offers`
- `POST /api/v1/campaigns`
- `GET /api/v1/campaigns/{id}`
- `PUT /api/v1/campaigns/{id}/country-filter`
- `POST /api/v1/campaigns/{id}/streams`
- `PUT /api/v1/campaigns/{id}/streams/{stream_id}/offers`
- `GET /api/v1/operations/{id}`

## 5. Ограничения MVP
- Глобальное создание/удаление офферов — нет.
- Изменение реквизитов/удаление кампаний — нет.
- Фильтры (кроме стран редиректа), лендинги, порядок потоков — просмотр; редактирование офферов и стран фильтрации.
- Отчёты — нет.
- Черновики — локальные (интерфейс).

## 6. Требования к дизайну (Tailwind + PrimeVue 4)
- **Цветовая схема**: Светлая/Темная (согласно настройкам PrimeVue).
- **Компоненты**:
  - `DataTable` для списков.
  - `Toast` для сообщений об ошибках (422, 404, 409, 502, 504) и успеха.
  - `Dialog` для создания кампании и редактирования офферов.
  - `ProgressBar` / `Spinner` для статусов операций (`running`, `unknown`).
  - `Tag` для состояний (`active`, `disabled`).
